# 经济自由本金计算器 · 2026

一个面向中国个人/家庭的经济自由（FIRE）本金模型：把支出、通胀、社保养老金、医疗、长期护理、子女、大额支出、长寿、收益序列和黑天鹅放在同一条现金流里，用蒙特卡洛和压力测试回答：

> 今天至少需要多少可投资净资产，才能在目标置信度下不再靠工作收入生活？

**这不是“保证一辈子不破产”的承诺。** 模型把“完全”翻译成“90% / 95% / 99% 的模拟人生不破产”，并把假设和代价标出来。

## 30 秒上手

1. 打开 HTML，先看右侧结果；手机上结果在参数前面。
2. 点“调整参数”，按 **家庭 → 开支 → 收入社保** 的顺序填真实数字。
3. 点“计算并更新”。重点看：
   - 90% 置信度所需本金；
   - 80/95/99 区间；
   - 当前资产成功率；
   - “4% 法则”对照；
   - 压力测试里的“退休后前 3 年连续大跌”。

**填表口径**
- 所有金额都是 **今天（2026）的购买力**。
- 可投资净资产 **不含自住房**。
- 核心生活 **不含房贷、保险、医疗**；这些单独填。
- 子女成本是“增量成本”，不含家庭共同住房。
- 养老金可以按公式估，也可以直接填预计月养老金。

## 默认结果（用于理解量级，不是你的答案）

默认：40/38 岁夫妻，一个 6 岁孩子，二线城市；可投资资产 300 万；自住房 300 万、房贷 100 万（3.2%，15 年）；核心生活 1.4 万/月；医疗 1,000/月；保险 1.2 万/年；现在停止工作；规划到 100 岁；90% 置信度。

| 指标 | 结果 |
|---|---|
| 90% 置信度所需本金 | **约 1,862 万元** |
| 80% / 95% / 99% | 1,482 / 2,268 / 3,414 万元 |
| 当前资产覆盖率 | 16.1% |
| 当前资产成功率 | 0% |
| 4% 法则 | 700 万元，在本模型下成功率 15.6% |
| 首年总支出 | 28.0 万元 |
| 当前资产可支撑核心生活费 | 0 元/月（90% 置信度下连固定支出都无法覆盖） |
| 社保养老金（今天币值） | 5,772 + 3,846 元/月 |

为什么不是 25 倍？因为 4% 法则对应美国 30 年、50/50 股债、通常未扣税费；这里是中国 60 年、费后几何 3.84%、通胀 2.0%，还要覆盖医疗、护理、子女、大件和序列风险。

## 模型结构

- **年度现金流**：年初收支，剩余资产按当年收益增长。
- **成功**：死亡前资产从未为负，且死亡时资产 ≥ 遗产目标（按 CPI 指数化）。
- **支出分项**：核心生活、医疗、保险、房贷、子女、大件、父母/护理；不同通胀。
- **收入**：停止工作前储蓄；社保养老金（国发〔2005〕38 号公式）；租金、半退休、一次性流入。
- **投资**：6 类资产配置 → 组合几何/算术收益与波动；t 分布 + 暴跌跳跃；费后/税后。
- **寿命**：男女分别的 Weibull 生存曲线；夫妻联合寿命；一方去世后支出降至 72%。
- **医疗/护理**：年龄相关的大额医疗冲击；失能发生率、持续年数、护理月费。
- **求解**：4,000 条路径 + 二分法；共同随机数；输出置信度曲线、敏感性、压力测试。

```powershell
# Python 性质测试
python tests\test_model.py

# JS/Python 交叉校验（确定性应一致；MC 有抽样误差）
node tests\compare_js.js
python tests\compare_py.py
python tests\show_compare.py
```

已验证：
- 11 个案例的确定性测算逐项一致（0.000%）；
- 2,000 路径下默认/低收益/遗产案例的 MC 差异约 1.0% / 2.4% / 2.7%；
- 成功率随本金、支出、置信度、遗产单调；
- 同一 seed 可复现；
- 零支出（同时关闭医疗/护理/保险）→ 零本金；
- 移动端结果优先、图表可横向滚动、无页面横向溢出。

## 边界

模型未单独建模：个人养老金账户税优、海外资产汇率、房产税全国推开、遗产税、离婚/再婚/丧偶状态机、子女啃老、诈骗/诉讼、保险拒赔、医保目录变化、地方养老金差异。它们会改变结果，方向不一定。

**本工具是规划工具，不构成投资、保险、税务或法律建议。** 所有“预期收益”都是假设，不是预测。
